# ARCY - Smart Desk Assistant

ARCY (Artificial Response Companion for You) is an ESP32-based smart desk assistant that displays time, weather, AQI, reminders, and tasks on an OLED display.

## Features
- OLED animated face UI
- Real-time clock using NTP
- Weather updates using OpenWeather API
- AQI monitoring using  openWeather API
- Task display using Blynk app

## Components Used
- ESP32
- OLED SSD1306 Display
- TTP223 Touch Sensor
- Lithium-ion Battery Module

## Technologies Used
- Embedded C++
- Arduino IDE
- ESP32 Wi-Fi
- I2C Communication
- Blynk IoT
- OpenWeather API
